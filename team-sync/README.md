# แชร์ข้อมูลทีมด้วย Google Sheet

ทำครั้งเดียวโดยหัวหน้าทีม ใช้เวลาประมาณ 5 นาที หลังจากนั้นทุกคนในทีมจะเห็น ดาว สถานะการขาย ผู้รับผิดชอบ นัด
บันทึกการติดต่อ เบอร์ที่แก้ รายชื่อทีม และผลตรวจข้อมูลซ้ำ เหมือนกันทุกเครื่อง

ข้อมูลทีมจะเก็บอยู่ใน Google Sheet ของคุณเอง (ชีตชื่อ `sync`) ส่วนไฟล์แนบ (ใบเสนอราคา / ใบแจ้งหนี้) เก็บในโฟลเดอร์
Google Drive ของคุณ ทั้งชีตและโฟลเดอร์ยังเป็นส่วนตัว คนในทีมไม่ต้องมีสิทธิ์เปิด
เว็บจะคุยกับชีตผ่าน Apps Script ที่ต้องใส่ **รหัสทีม** ทุกครั้ง

## ขั้นตอน

> ถ้าหน้าจอ Apps Script เป็นภาษาไทย ชื่อปุ่มจะเป็นภาษาไทยแต่อยู่ตำแหน่งเดิม: **Run** คือปุ่มรูป ▷ ในแถบด้านบน
> และ **Deploy** คือปุ่มสีน้ำเงินมุมขวาบน (ภาษาไทยประมาณว่า "การทำให้ใช้งานได้") ตัวเลือกในหน้า Deploy ให้เลือก
> **Web app / เว็บแอป**, ทำงานในฐานะ **Me / ฉัน** และผู้มีสิทธิ์เข้าถึง **Anyone / ทุกคน**

1. **สร้างชีต** เปิด <https://sheets.new> แล้วตั้งชื่อ เช่น `GCC ข้อมูลทีม`
2. **เปิด Apps Script** เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. **วางโค้ด** ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ในโฟลเดอร์นี้
   (เปิดไฟล์แล้วกดปุ่ม **Copy raw file** มุมขวาบน)
4. **ตั้งรหัสทีม** แก้บรรทัด

   ```js
   const TEAM_KEY = '';
   ```

   ใส่รหัสที่**สุ่มขึ้นมาเอง** ยาวอย่างน้อย 8 ตัวอักษร (ยาว 12 ตัวขึ้นไปจะดีกว่า) ผสมตัวอักษรกับตัวเลข
   ไว้ระหว่างเครื่องหมาย `'…'` อย่าใช้ชื่อบริษัท ปี หรือคำที่เดาง่าย แล้วกด **บันทึก** (ไอคอนแผ่นดิสก์)
5. **อนุญาตสิทธิ์** ดูช่องเลือกฟังก์ชันข้างปุ่ม **Run** (แถบด้านบน) ให้เป็น `setup` แล้วกด **Run**
   - Google จะขออนุญาต: **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow**
     (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่คุณสร้างเอง ยังไม่ได้ส่งให้ Google ตรวจ
     และจะมีสิทธิ์ Google Drive ด้วย สำหรับเก็บไฟล์แนบ — ดูเหตุผลที่หัวข้อ [แนบเอกสาร](#แนบเอกสาร-ใบเสนอราคา--ใบแจ้งหนี้))
   - ถ้าสำเร็จ กล่อง **Execution log** ด้านล่างจะขึ้น "พร้อมใช้งาน: สร้างชีต "sync" และโฟลเดอร์ … แล้ว"
     ในไฟล์ Google Sheet จะมีแท็บใหม่ชื่อ `sync` ที่แถบล่าง (ถ้ายังไม่เห็น ให้รีเฟรชหน้าชีต)
     และใน Google Drive จะมีโฟลเดอร์ **GCC Sales Tracker — เอกสาร**
   - ถ้าข้ามขั้นนี้ไปก็ไม่เป็นไร ชีต `sync` จะถูกสร้างเองตอนกด **เชื่อมต่อ** ในเว็บครั้งแรก
6. **เผยแพร่เป็น Web app** กด **Deploy → New deployment** → กดรูปเฟือง ⚙ เลือก **Web app**
   - **Execute as:** `Me`
   - **Who has access:** `Anyone` (ทุกคน — จำเป็น เพื่อให้เว็บเรียกได้ แต่ทุกคำขอต้องมีรหัสทีม)
   - กด **Deploy** แล้ว **คัดลอก Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/…` และ**ลงท้ายด้วย `/exec`**
     — อย่าใช้ลิงก์ทดสอบที่ลงท้ายด้วย `/dev`)
7. **เชื่อมต่อในเว็บ** เปิดเว็บ → แท็บ **อัปเดตข้อมูล** → การ์ด **แชร์ข้อมูลทีม** → วาง URL และใส่รหัสทีม → กด **เชื่อมต่อ**
   - ข้อมูลที่เคยบันทึกไว้ในเครื่องนี้จะถูกส่งขึ้นชีตด้วย
8. **ชวนทีม** กด **คัดลอกลิงก์เชิญทีม** ส่งให้เพื่อน แล้วบอก **รหัสทีม** แยกต่างหาก
   - เพื่อนเปิดลิงก์ → ใส่รหัสทีม → กดเชื่อมต่อ (ข้อมูลที่เขาบันทึกไว้ในเครื่องก่อนหน้าจะถูกรวมเข้ามาด้วย)
   - หน้าเชิญจะขึ้น **ชีตรหัส …XXXXXXXXXX** ให้เพื่อนเทียบกับช่อง **รหัสชีตของทีม** ในการ์ดของคุณ
     ถ้าไม่ตรงกัน แปลว่าลิงก์ไม่ได้มาจากคุณ อย่าใส่รหัสทีม

## ใช้งาน

- เว็บจะส่งข้อมูลขึ้นชีตทันทีที่แก้ไข และดึงของคนอื่นทุก 30 วินาที (และทุกครั้งที่กลับมาที่หน้าเว็บ)
- มุมขวาบนของเว็บจะมีป้าย **ทีม · ซิงก์แล้ว 14:05** บอกสถานะ ถ้าเน็ตหลุด ข้อมูลที่แก้จะรอในเครื่อง แล้วส่งให้เองเมื่อต่อได้
- ถ้าสองคนแก้รายการเดียวกัน (เช่น สถานะการขายของบริษัทเดียวกัน) จะใช้ค่าที่ถึงชีตทีหลัง
- ในเว็บ ให้แต่ละคนเลือก **ฉันคือ** (แท็บอัปเดตข้อมูล) เพื่อให้บันทึกการติดต่อมีชื่อคนบันทึก

## แนบเอกสาร (ใบเสนอราคา / ใบแจ้งหนี้)

ในหน้า Sales Tracker แนบไฟล์ใบเสนอราคาและใบแจ้งหนี้ไว้กับรายการขายได้ ไฟล์จะเก็บใน Google Drive **ของคุณ**
(บัญชีที่เป็นเจ้าของสคริปต์) ในโฟลเดอร์ **GCC Sales Tracker — เอกสาร** ซึ่งสคริปต์สร้างให้เอง

- **คนในทีมเปิดไฟล์จากในเว็บได้เลย** เว็บขอไฟล์ผ่านสคริปต์ด้วยรหัสทีม ไม่ต้องแชร์โฟลเดอร์ และคนในทีมไม่ต้องมีสิทธิ์ใน Google Drive ของคุณ
- **ไฟล์ละไม่เกิน 10 MB** รองรับ **PDF** และรูปภาพ **PNG, JPG, WEBP, HEIC** (รูปจาก iPhone)
- **ลบไฟล์แนบในเว็บ** = ย้ายไฟล์ไปถังขยะของ Drive คุณ กู้คืนได้ภายใน 30 วัน
- ชื่อไฟล์ใน Drive ขึ้นต้นด้วยรหัสรายการ เช่น `d123__ใบเสนอราคา QT-001.pdf` เพื่อให้รู้ว่าเป็นของรายการไหน
- **อย่าย้ายไฟล์ออกจากโฟลเดอร์ (รวมถึงเข้าโฟลเดอร์ย่อย)** สคริปต์เปิดให้ทีมเฉพาะไฟล์ที่อยู่ในโฟลเดอร์นี้โดยตรงเท่านั้น
- **ถ้าลบโฟลเดอร์ทิ้ง** ไฟล์ใหม่จะเข้าโฟลเดอร์ใหม่ที่สร้างให้อัตโนมัติ แต่ไฟล์เดิมจะเปิดจากเว็บไม่ได้
  ถ้าลบโดยไม่ตั้งใจ ให้กู้คืนโฟลเดอร์จากถังขยะ**ก่อน**มีคนแนบไฟล์ใหม่ ไฟล์เดิมจะกลับมาเปิดได้
- ไฟล์แนบใช้พื้นที่ Google Drive ของคุณ (บัญชีฟรีมี 15 GB ใช้ร่วมกับ Gmail และ Google Photos)

### อัปเดตสคริปต์ (ทีมที่ตั้งค่าไว้ก่อนมีการแนบเอกสาร)

ถ้าตอนแนบไฟล์ในเว็บขึ้นว่า **"สคริปต์ของทีมยังเป็นเวอร์ชันเก่า"** หัวหน้าทีมต้องอัปเดตโค้ดครั้งเดียว ประมาณ 3 นาที:

1. เปิดไฟล์ Google Sheet ของทีม → **ส่วนขยาย (Extensions) → Apps Script**
2. **เก็บรหัสทีมเดิมไว้ก่อน** คัดลอกบรรทัด `const TEAM_KEY = '…';` ทั้งบรรทัดไปวางพักไว้ (เช่นใน Notepad)
3. ลบโค้ดเดิมทั้งหมด วางโค้ดใหม่จากไฟล์ [`Code.gs`](Code.gs) แล้ว**แทนบรรทัด `const TEAM_KEY = '';` ด้วยบรรทัดที่เก็บไว้** → กด **บันทึก**
   - ต้องเป็นรหัสเดิม ไม่อย่างนั้นทุกเครื่องจะขึ้น "รหัสทีมไม่ถูกต้อง"
4. เลือกฟังก์ชัน `setup` ในช่องข้างปุ่ม **Run** แล้วกด **Run** → Google จะขออนุญาตอีกครั้ง →
   **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow**
   - **ทำไมรอบนี้ Google ขอสิทธิ์ Google Drive** (ขึ้นประมาณว่า *See, edit, create, and delete all of your Google Drive files*)
     เพราะสคริปต์ต้องสร้างโฟลเดอร์และบันทึกไฟล์แนบลง Drive ของคุณ Google ไม่มีตัวเลือกให้สคริปต์ขอสิทธิ์เฉพาะโฟลเดอร์เดียว
     จึงแสดงเป็นสิทธิ์ทั้ง Drive แต่โค้ดจะเปิดหรือลบ**เฉพาะไฟล์ในโฟลเดอร์ GCC Sales Tracker — เอกสาร** (ตรวจทุกครั้งก่อนเปิดหรือลบ)
     ไฟล์อื่นใน Drive ของคุณไม่ถูกแตะ และสิทธิ์นี้เป็นของสคริปต์ที่ทำงานในนามคุณ ไม่ใช่ของคนในทีม
   - สำเร็จเมื่อ **Execution log** ขึ้น "พร้อมใช้งาน: … โฟลเดอร์ "GCC Sales Tracker — เอกสาร" …" และเห็นโฟลเดอร์นี้ใน Google Drive
5. **Deploy → Manage deployments** → กด ✏️ (**Edit**) → ช่อง **Version** เลือก **New version** → **Deploy**
   - URL เดิมยังใช้ได้ คนในทีมไม่ต้องทำอะไร
   - กดแค่ **บันทึก** ยังไม่พอ เว็บใช้โค้ดเวอร์ชันที่ Deploy ไว้ และอย่ากด **New deployment** (จะได้ URL ใหม่ ทุกคนต้องเชื่อมต่อใหม่)
   - ทำข้อ 4 ก่อนข้อ 5 ถ้า Deploy ไปก่อนแล้ว ให้กลับไปทำข้อ 4 (Run `setup` → Allow) แล้วจะใช้ได้เอง

## ข้อควรรู้

- **อย่าแก้ข้อมูลในชีต `sync` ด้วยมือ** แต่ละแถวคือการเปลี่ยนแปลงหนึ่งครั้ง (seq, k, v, del, by, at) ระบบจะลบแถวเก่าที่ถูกแทนที่แล้วให้เองเมื่อชีตยาวขึ้น
- **เปลี่ยนรหัสทีม** แก้ `TEAM_KEY` แล้ว Deploy เวอร์ชันใหม่ (ดูด้านล่าง) ทุกเครื่องจะขึ้นว่า "รหัสทีมไม่ถูกต้อง"
  พร้อมช่อง **รหัสทีมใหม่** ใส่รหัสใหม่แล้วกด **ใช้รหัสใหม่** ข้อมูลที่ค้างส่งจะถูกส่งต่อให้ ไม่ต้องยกเลิกการเชื่อมต่อ
- **แก้โค้ดสคริปต์ภายหลัง** ใช้ **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** URL จะเหมือนเดิม
  (ถ้ากด New deployment จะได้ URL ใหม่ และทุกคนต้องเชื่อมต่อใหม่)
- **ย้ายไปลิงก์ใหม่** กด **ยกเลิกการเชื่อมต่อ** (เว็บจะลองส่งรายการที่ค้างให้ลิงก์เดิมก่อน) แล้วเชื่อมใหม่ด้วยลิงก์เชิญอันใหม่
  รายการที่ยังส่งไม่ได้จะตามไปส่งที่ลิงก์ใหม่
- **เปิดหลายแท็บ** ทุกแท็บในเบราว์เซอร์เดียวกันใช้การเชื่อมต่อเดียวกัน เชื่อมต่อ/ยกเลิก/เปลี่ยนรหัสในแท็บหนึ่ง แท็บอื่นจะทำตาม
- **ความปลอดภัย** คนที่มีทั้ง URL และรหัสทีม อ่านและแก้ข้อมูลทีมได้ รวมถึงเปิด แนบ และลบไฟล์แนบ ส่งรหัสทีมให้เฉพาะคนในทีม
  ส่วนไฟล์ Google Sheet และโฟลเดอร์ใน Drive ยังเปิดได้เฉพาะคุณ
- **โควตา** Apps Script ฟรีพอสำหรับทีมเล็ก (หลายคน ใช้ทั้งวัน)
- **นำเข้าไฟล์สำรองตอนเชื่อมต่ออยู่** จะเพิ่มเฉพาะรายการที่ทีมยังไม่มี รายการที่ทีมมีแล้ว (หรือลบไปแล้ว) ใช้ค่าของทีม
- **บริษัทที่ดึงเพิ่มจากเว็บ TGO** (รหัส TGO-…) เป็นของแต่ละเครื่อง ดาว สถานะ นัด และบันทึกของบริษัทกลุ่มนี้จึงไม่แชร์
- **สิทธิ์ของสคริปต์** ชีต: เฉพาะไฟล์นี้ (`@OnlyCurrentDoc`) ไม่ได้แตะ Google Sheet ไฟล์อื่นของคุณ
  Drive: ใช้เฉพาะโฟลเดอร์ **GCC Sales Tracker — เอกสาร** สำหรับไฟล์แนบ (ดูหัวข้อแนบเอกสาร)

## ปัญหาที่พบบ่อย

| ข้อความในเว็บ | วิธีแก้ |
| --- | --- |
| เชื่อมต่อไม่ได้ — ตรวจว่าใช้ลิงก์ … /exec … Anyone | ตอน Deploy ตั้ง **Who has access** เป็น **Anyone** หรือยัง และใช้ลิงก์ที่ลงท้ายด้วย `/exec` |
| สคริปต์ยังไม่มีรหัสทีม | ใส่ `TEAM_KEY` (อย่างน้อย 8 ตัว) แล้ว **Deploy → Manage deployments → ✏️ Edit → New version** |
| รหัสทีมไม่ถูกต้อง | ตรวจรหัสกับหัวหน้าทีม (ตัวพิมพ์เล็ก/ใหญ่ต้องตรงกัน) |
| ชีตไม่ตอบกลับ / เชื่อมต่อชีตไม่ได้ชั่วคราว | ระหว่างใช้งานจะหายเอง (เว็บลองใหม่ทุก 30 วินาที) ถ้าขึ้นตอนกด **เชื่อมต่อ** หรือ **ใช้รหัสใหม่** ให้กดอีกครั้ง ถ้าเป็นนาน ตรวจว่าเปิดเว็บ Google ได้ และสคริปต์ยัง Deploy อยู่ |
| ไม่เห็นชีต `sync` หลังกด Run | ช่องข้างปุ่ม Run ต้องเป็น `setup` (ไม่ใช่ `doGet`) แล้วดูข้อความใน **Execution log** ด้านล่าง |

## สำหรับนักพัฒนา

- `Code.gs` — สคริปต์ฝั่ง Google (protocol อธิบายไว้ต้นไฟล์)
- `sim.mjs` — รัน `Code.gs` ตัวจริงใน Node ด้วย Google services จำลอง (รวม DriveApp / Utilities) ใช้ในชุดทดสอบ
  (`app/src/lib/teamSync.test.ts`, `app/src/lib/teamFiles.test.ts`)
- `dev-server.mjs` — เซิร์ฟเวอร์ทดสอบในเครื่อง: `node team-sync/dev-server.mjs 8787 test-key-123`
  แล้วเชื่อมต่อในเว็บด้วย URL `http://localhost:8787` และรหัส `test-key-123` (ไฟล์แนบเก็บในหน่วยความจำ หายเมื่อปิดเซิร์ฟเวอร์)
- ฝั่งเว็บ: `app/src/lib/teamSync.ts` (transport, record keys, apply), ส่วน team sync ใน `app/src/lib/engine.ts`
  และ `app/src/lib/teamFiles.ts` (อัปโหลด / เปิด / ลบไฟล์แนบ)
