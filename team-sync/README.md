# แชร์ข้อมูลทีมด้วย Google Sheet

ทำครั้งเดียวโดยหัวหน้าทีม ใช้เวลาประมาณ 5 นาที หลังจากนั้นทุกคนในทีมจะเห็น ดาว สถานะการขาย ผู้รับผิดชอบ นัด
บันทึกการติดต่อ เบอร์ที่แก้ รายชื่อทีม และผลตรวจข้อมูลซ้ำ เหมือนกันทุกเครื่อง

ข้อมูลทีมจะเก็บอยู่ใน Google Sheet ของคุณเอง (ชีตชื่อ `sync`) ตัวชีตยังเป็นส่วนตัว คนในทีมไม่ต้องมีสิทธิ์เปิดชีต
เว็บจะคุยกับชีตผ่าน Apps Script ที่ต้องใส่ **รหัสทีม** ทุกครั้ง

## ขั้นตอน

1. **สร้างชีต** เปิด <https://sheets.new> แล้วตั้งชื่อ เช่น `GCC ข้อมูลทีม`
2. **เปิด Apps Script** เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. **วางโค้ด** ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ [`Code.gs`](Code.gs) ในโฟลเดอร์นี้
   (เปิดไฟล์แล้วกดปุ่ม **Copy raw file** มุมขวาบน)
4. **ตั้งรหัสทีม** แก้บรรทัด

   ```js
   const TEAM_KEY = '';
   ```

   เป็นรหัสของทีม อย่างน้อย 6 ตัวอักษร เช่น `const TEAM_KEY = 'gcc-team-2569';` แล้วกด **บันทึก** (ไอคอนแผ่นดิสก์)
5. **อนุญาตสิทธิ์** เลือกฟังก์ชัน `setup` ในแถบด้านบน แล้วกด **Run**
   - Google จะขออนุญาต: **Review permissions** → เลือกบัญชี → **Advanced** → **Go to … (unsafe)** → **Allow**
     (ขึ้นคำว่า unsafe เพราะเป็นสคริปต์ที่คุณสร้างเอง ยังไม่ได้ส่งให้ Google ตรวจ)
   - ถ้าสำเร็จ จะเห็นชีตใหม่ชื่อ `sync` ในไฟล์ Google Sheet
6. **เผยแพร่เป็น Web app** กด **Deploy → New deployment** → กดรูปเฟือง ⚙ เลือก **Web app**
   - **Execute as:** `Me`
   - **Who has access:** `Anyone` (ทุกคน — จำเป็น เพื่อให้เว็บเรียกได้ แต่ทุกคำขอต้องมีรหัสทีม)
   - กด **Deploy** แล้ว **คัดลอก Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/…/exec`)
7. **เชื่อมต่อในเว็บ** เปิดเว็บ → แท็บ **อัปเดตข้อมูล** → การ์ด **แชร์ข้อมูลทีม** → วาง URL และใส่รหัสทีม → กด **เชื่อมต่อ**
   - ข้อมูลที่เคยบันทึกไว้ในเครื่องนี้จะถูกส่งขึ้นชีตด้วย
8. **ชวนทีม** กด **คัดลอกลิงก์เชิญทีม** ส่งให้เพื่อน แล้วบอก **รหัสทีม** แยกต่างหาก
   เพื่อนเปิดลิงก์ → ใส่รหัสทีม → กดเชื่อมต่อ (ข้อมูลที่เขาบันทึกไว้ในเครื่องก่อนหน้าจะถูกรวมเข้ามาด้วย)

## ใช้งาน

- เว็บจะส่งข้อมูลขึ้นชีตทันทีที่แก้ไข และดึงของคนอื่นทุก 30 วินาที (และทุกครั้งที่กลับมาที่หน้าเว็บ)
- มุมขวาบนของเว็บจะมีป้าย **ทีม · ซิงก์แล้ว 14:05** บอกสถานะ ถ้าเน็ตหลุด ข้อมูลที่แก้จะรอในเครื่อง แล้วส่งให้เองเมื่อต่อได้
- ถ้าสองคนแก้รายการเดียวกัน (เช่น สถานะการขายของบริษัทเดียวกัน) จะใช้ค่าที่ถึงชีตทีหลัง
- ในเว็บ ให้แต่ละคนเลือก **ฉันคือ** (แท็บอัปเดตข้อมูล) เพื่อให้บันทึกการติดต่อมีชื่อคนบันทึก

## ข้อควรรู้

- **อย่าแก้ข้อมูลในชีต `sync` ด้วยมือ** แต่ละแถวคือการเปลี่ยนแปลงหนึ่งครั้ง (seq, k, v, del, by, at) ระบบจะลบแถวเก่าที่ถูกแทนที่แล้วให้เองเมื่อชีตยาวขึ้น
- **เปลี่ยนรหัสทีม** แก้ `TEAM_KEY` แล้ว Deploy ใหม่ (ดูด้านล่าง) ทุกคนต้องกด **ยกเลิกการเชื่อมต่อ** แล้วเชื่อมต่อใหม่ด้วยรหัสใหม่
- **แก้โค้ดสคริปต์ภายหลัง** ใช้ **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy** URL จะเหมือนเดิม
  (ถ้ากด New deployment จะได้ URL ใหม่ และทุกคนต้องเชื่อมต่อใหม่)
- **ความปลอดภัย** คนที่มีทั้ง URL และรหัสทีม อ่านและแก้ข้อมูลทีมได้ ส่งรหัสทีมให้เฉพาะคนในทีม ส่วนไฟล์ Google Sheet ยังเปิดได้เฉพาะคุณ
- **โควตา** Apps Script ฟรีพอสำหรับทีมเล็ก (หลายคน ใช้ทั้งวัน)

## สำหรับนักพัฒนา

- `Code.gs` — สคริปต์ฝั่ง Google (protocol อธิบายไว้ต้นไฟล์)
- `sim.mjs` — รัน `Code.gs` ตัวจริงใน Node ด้วย Google services จำลอง ใช้ในชุดทดสอบ (`app/src/lib/teamSync.test.ts`)
- `dev-server.mjs` — เซิร์ฟเวอร์ทดสอบในเครื่อง: `node team-sync/dev-server.mjs 8787 test-key-123`
  แล้วเชื่อมต่อในเว็บด้วย URL `http://localhost:8787` และรหัส `test-key-123`
- ฝั่งเว็บ: `app/src/lib/teamSync.ts` (transport, record keys, apply) และส่วน team sync ใน `app/src/lib/engine.ts`
