# ฐานข้อมูลลูกค้า GCC (GCC Registry)

เว็บสำหรับทีมขายใช้ติดตามลูกค้า CFO / GI / โรงงานใหม่ (กรอ.) / บริษัทจดทะเบียน (SET) ในที่เดียว
สร้างจากแบบที่ออกแบบใน Claude Design

**เว็บ:** https://mktwni.github.io/customer_vvb/

> ⚠️ เว็บนี้เป็นสาธารณะ ใครมีลิงก์ก็เปิดดูข้อมูลบริษัท เบอร์โทร และอีเมลในเว็บได้

## Sales Tracker

เมนู **Sales Tracker** ด้านซ้าย คือตารางติดตามสถานะการขาย (เดิมคือไฟล์ "Sales Tracker 2569") รวมอยู่ในเว็บนี้แล้ว

- **ส่งลูกค้าเข้าตาราง** ไม่ต้องพิมพ์ซ้ำ: ปุ่ม **ส่งเข้า Sales Tracker** ในหน้าบริษัท, ในแผนติดต่อ (เลือกหลายราย), ในการ์ด "ติดดาว"
  หรือ **+ เพิ่มลูกค้า → ส่งบริษัทที่ติดดาว** — ชื่อ เบอร์ อีเมล และผู้รับผิดชอบกรอกให้เอง
- **เพิ่มลูกค้าที่ไม่มีในทะเบียน** ได้เอง (ปุ่ม **+ เพิ่มลูกค้าใหม่** ในหน้าค้นหา หรือใน Sales Tracker) ระบบเตือนถ้ามีบริษัทชื่อคล้ายกันอยู่แล้ว
- **แนบใบเสนอราคา / ใบแจ้งหนี้** แล้วระบบอ่านยอดเงินให้ (PDF อ่านข้อความ, รูปถ่าย/สแกนใช้ OCR ภาษาไทย อ่านในเบราว์เซอร์ ไม่ส่งไฟล์ไปที่อื่น)
  ยอดจะถูกใช้เป็น Forecast / Actual **หลังจากกดยืนยัน** เท่านั้น และแสดงเครื่องหมาย ✓ ว่ายืนยันด้วยเอกสาร
- ไฟล์แนบเก็บใน Google Drive ของหัวหน้าทีม ผ่านสคริปต์เดียวกับการแชร์ข้อมูลทีม (ดู [`team-sync/README.md`](team-sync/README.md#แนบเอกสาร-ใบเสนอราคา--ใบแจ้งหนี้))
- ย้ายข้อมูลจากไฟล์เดิม: **เพิ่มเติม → นำเข้าจาก Sales Tracker เดิม** (ไฟล์สำรอง JSON หรือ Google Sheet ที่ดาวน์โหลดเป็น CSV / Excel)
  นำเข้าซ้ำได้ ไม่สร้างรายการซ้ำและไม่เขียนทับสิ่งที่ทีมแก้ไว้

## โครงสร้าง

| โฟลเดอร์ | คืออะไร |
| --- | --- |
| `app/` | ตัวเว็บ (React + Vite + TypeScript) — ดูวิธีรันและโครงสร้างโค้ดใน [`app/README.md`](app/README.md) |
| `project/data/` | ไฟล์ข้อมูลที่เว็บใช้ (`gcc.json`, `gcc-certs.json`, `gcc-detail/`, `rounds.json`, …) |
| `project/*.dc.html`, `project/*.js` | ไฟล์ต้นแบบจาก Claude Design (ใช้อ้างอิงหน้าตาและการทำงาน) |
| `.github/workflows/deploy-pages.yml` | build และขึ้นเว็บบน GitHub Pages อัตโนมัติทุกครั้งที่ push เข้า `main` |

ไฟล์ Excel ต้นฉบับ (`project/uploads/`) และบันทึกการคุยออกแบบ (`chats/`) ไม่ได้เก็บไว้ใน repo นี้

## รันบนเครื่อง

```bash
cd app
npm install
npm run dev     # http://localhost:5173
npm test
```

## อัปเดตข้อมูลบนเว็บ

แก้หรือแทนที่ไฟล์ใน `project/data/` แล้ว push เข้า `main` — ระบบจะ build และขึ้นเว็บใหม่ให้เอง
(การอัปโหลด Excel ในแท็บ "อัปเดตข้อมูล" บนเว็บ จะเก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น)
